## กฎการอัปเดตไฟล์นี้

เมื่อ AI สร้างเอกสาร Sx เสร็จ:
1. เปลี่ยนสถานะ Sx จาก ⬜ เป็น ✅
2. บันทึกวันที่ในคอลัมน์ "อัปเดตล่าสุด"
3. เพิ่มบันทึกใน "ประวัติการอัปเดต"

เมื่อพัฒนา Feature ใหม่เสร็จ:
1. ย้ายจาก "กำลังพัฒนา" → "พัฒนาเสร็จแล้ว"
2. อัปเดต "Known Issues" ถ้า Fix แล้ว
3. แจ้ง S หัวข้อที่ต้องอัปเดตตาม
