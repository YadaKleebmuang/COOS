# COOS — Gemini / Antigravity Entry Point

This repository already defines its canonical AI working protocol.

Before non-trivial work:
1. Read `/AGENTS.md`.
2. Follow active workspace rules under `/.agents/rules/`.
3. Load relevant skills under `/.agents/skills/` when applicable.
4. Read relevant repository documentation before modifying behavior.
5. For UI work, read `docs/design-system/COOS_DESIGN_SYSTEM_V1.md` when present.
6. Inspect Git branch, working tree, existing WIP, and target implementation before editing.
7. Distinguish verification evidence:
   - code audit
   - executed build/test/API verification
   - browser/manual verification
8. Never claim a verification level that was not actually performed.
9. Do not commit, push, merge, deploy, delete shared data, or perform irreversible/outward-facing actions without explicit user authorization.
10. Stop at the requested checkpoint.

`AGENTS.md` and `.agents/` are authoritative. If this file conflicts with them, follow `AGENTS.md` and `.agents/`. Do not duplicate project rules here.
